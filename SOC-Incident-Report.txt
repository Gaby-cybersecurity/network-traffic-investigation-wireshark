Case Title:
Suspicious PowerShell Execution Investigation

Case Type:
Endpoint / PowerShell Investigation

Environment:
Controlled Windows Laboratory Environment

Investigation Date:

-----------------------------------------
1. EXECUTIVE SUMMARY
-----------------------------------------

A suspicious PowerShell process execution was identified through
Sysmon Event ID 1 (Process Create).

The observed PowerShell process used the -EncodedCommand parameter,
which is an investigation-relevant indicator because encoded PowerShell
can conceal command content from straightforward visual inspection.

The encoded command was extracted from the Sysmon event and successfully
decoded. The decoded output was:

SOC Project 2 - Suspicious PowerShell Test

The investigation was performed in a controlled laboratory environment.
The decoded command produced the expected test output.

Additional correlation searches were performed against the Windows
PowerShell Operational log and Sysmon Operational log. These searches
did not produce additional confirmed events directly correlating to
the investigated process ID or queried event types.

Based on the available evidence, the activity is documented as
suspicious-looking PowerShell execution within a controlled laboratory
exercise. The available evidence does not establish malicious activity.

-----------------------------------------
8. INVESTIGATION ASSESSMENT
-----------------------------------------

The investigation identified a suspicious PowerShell execution pattern,
primarily due to the use of -EncodedCommand.

Encoded PowerShell commands can conceal readable command content and
therefore warrant investigation in a SOC environment.

In this controlled laboratory exercise, however, the decoded command
produced the expected project test message.

The evidence therefore demonstrates the investigation and analysis
workflow for suspicious PowerShell activity without establishing that
the observed activity was malicious.

-----------------------------------------
9. CONCLUSION
-----------------------------------------

The investigation successfully identified, extracted, decoded, and
analyzed a suspicious-looking PowerShell execution.

The available evidence does not establish confirmed malicious activity.

The process information, SHA256 hash, encoded command indicator,
decoded output, and timeline should be preserved as investigation
artifacts for future comparison, enrichment, or additional analysis.

-----------------------------------------
10. RECOMMENDED SOC ACTIONS
-----------------------------------------

If equivalent activity were observed on a production endpoint, an
analyst should:

1. Review the complete PowerShell command and decoded content.
2. Identify the initiating user and parent process.
3. Correlate the process with authentication, network, and endpoint
   telemetry.
4. Review surrounding process creation events.
5. Investigate associated files and hashes.
6. Determine whether the activity is authorized or expected.
7. Preserve relevant evidence before making containment decisions.
8. Escalate the investigation if additional malicious indicators
   are identified.
