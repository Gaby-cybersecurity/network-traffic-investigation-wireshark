
# Network Traffic Investigation with Wireshark

## Project Overview

This project demonstrates a hands-on network traffic investigation performed in a controlled security lab environment using Wireshark.

The investigation focuses on capturing and analyzing network traffic, identifying communication patterns, examining protocols, and documenting findings from a SOC Analyst perspective.

## Objectives

- Capture network traffic in a controlled environment
- Analyze packets using Wireshark
- Identify commonly used network protocols
- Examine source and destination IP addresses
- Investigate network communication patterns
- Identify potentially suspicious or unusual traffic
- Document investigation findings and evidence
- Practice basic network traffic analysis techniques used in Security Operations Centers (SOCs)

## Environment

- Windows laboratory environment
- Wireshark
- Controlled test network traffic
- PCAP/PCAPNG network capture files

## Investigation Methodology

The investigation was performed using the following process:

1. Capture network traffic using Wireshark
2. Review captured packets and protocol information
3. Identify source and destination hosts
4. Examine communication patterns
5. Apply Wireshark display filters
6. Investigate relevant packets in greater detail
7. Document observations and findings
8. Preserve the network capture as investigation evidence

## Key Areas Investigated

### 1. Network Traffic Capture

A controlled network traffic capture was performed using Wireshark.

The resulting PCAPNG file was preserved as evidence for further analysis.

### 2. Protocol Analysis

Captured traffic was reviewed to identify protocols and understand how systems were communicating across the network.

### 3. IP Address Analysis

Source and destination IP addresses were examined to understand the hosts involved in the observed communications.

### 4. Packet Analysis

Individual packets were inspected to understand:

- Source and destination information
- Protocols
- Ports
- Packet contents
- Communication patterns

### 5. Suspicious Traffic Investigation

Traffic was reviewed for unusual or potentially suspicious communication patterns.

Any observations were documented and assessed within the context of the controlled laboratory environment.
